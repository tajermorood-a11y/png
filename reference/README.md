# reference/ — ملفات مرجعية جاهزة (جزئية)

هذه الملفات **مكتوبة ومتوافقة مع المواصفات**، تُعطى للنموذج الجديد ليأخذها كما هي:
- `package.json`, `app.config.js`, `eas.json`, `babel.config.js`, `.env.example`
- `src/constants` (config + strings العربية)، `src/lib` (supabase + errors + api)، `src/store/authStore.js`، `src/utils/format.js`
- `src/finance/` كاملاً: البوكس المالي، النافذة، التعبئة، النجمة، الأود، حاجز التوثيق.

**غير موجود هنا (يبنيه النموذج حسب المواصفات):** مجلد `app/` (الشاشات) ومكوّنات `src/components`.
هذا ليس تطبيقاً يعمل بعد، لأن الشاشات ناقصة.
